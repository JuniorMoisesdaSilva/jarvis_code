# Credit and origin

The files in the folders beside this one are literal copies of the skills in the
`mattpocock-skills` package, version 1.2.3, written by Matt Pocock and distributed
under the MIT licence (see `LICENSE`). Nothing in their contents was changed.

They are here so the maestro works on machines and tools where the original
package is not installed. When the package is present, the maestro reads the
installed files and ignores these copies.

Original package: https://github.com/mattpocock (the official Claude Code plugin catalogue)
Skill documentation: https://aihero.dev
